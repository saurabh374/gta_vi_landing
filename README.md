
# GTA VI Landing Page

A sleek, animated landing page inspired by the upcoming Grand Theft Auto VI game. Built with React, Tailwind CSS, and GSAP for smooth scroll-driven animations and visual storytelling.

## Features

- Scroll-driven cinematic effects using GSAP ScrollTrigger
- Pinned sections with parallax and layered animations
- Scroll-synced video playback
- Responsive design powered by Tailwind CSS
- Clean and modular React component structure

## Tech Stack

- React for interactive UI
- Tailwind CSS for utility-first styling
- GSAP for performant animations
- Vite for fast development and build tooling

## Getting Started

1. Clone the repo:
   ```
   git clone https://github.com/saurabh374/gta_vi_landing.git
   cd gta_vi_landing
   ```
2. Install dependencies:
   ```
   npm install
   ```
3. Run the dev server:
   ```
   npm run dev
   ```
4. Open [http://localhost:5173](http://localhost:5173) in your browser to view
